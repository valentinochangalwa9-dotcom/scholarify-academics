SCHOLARIFY ACADEMICS WEBSITE

Files:
- index.html  = main website
- style.css   = design and responsive layout
- script.js   = mobile menu, year and contact form behavior
- assets/     = folder for future images/logo files

GITHUB PAGES:
1. Create a public GitHub repository, e.g. scholarify-academics.
2. Upload index.html, style.css, script.js and the assets folder.
3. Go to Settings > Pages.
4. Under Build and deployment choose "Deploy from a branch".
5. Select branch "main" and folder "/ (root)".
6. Save.
7. GitHub will give you the live website address.

IMPORTANT:
The contact form is currently a front-end demonstration. GitHub Pages does not provide a server/database for receiving form submissions.
Before launch, connect the form to your preferred email/form service or replace it with your WhatsApp contact button.
